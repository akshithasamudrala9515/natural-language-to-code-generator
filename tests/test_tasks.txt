TASK 1:
Write a Python function called reverse_string(text) that returns the reversed string.

It must pass:
assert reverse_string("abc") == "cba"
assert reverse_string("hello") == "olleh"


TASK 2:
Write a Python function called is_even(number) that returns True if the number is even and False otherwise.

It must pass:
assert is_even(4) == True
assert is_even(7) == False
assert is_even(100) == True


TASK 3:
Write a Python function called find_max(numbers) that returns the largest number from a list.

It must pass:
assert find_max([1, 5, 3]) == 5
assert find_max([10, 20, 15]) == 20


TASK 4:
Write a Python function called count_vowels(text) that returns the number of vowels in a string.

It must pass:
assert count_vowels("hello") == 2
assert count_vowels("education") == 5
assert count_vowels("xyz") == 0


TASK 5:

It must pass:
assert factorial(5) == 120
assert factorial(3) == 6
assert factorial(0) == 1
